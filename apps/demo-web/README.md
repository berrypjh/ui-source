# @berrypjh/demo-web

`@berrypjh/react-ui` 컴포넌트 라이브러리의 웹 데모 애플리케이션입니다.

## 실행

```bash
# 개발 서버 (http://localhost:4200)
pnpm exec nx run @berrypjh/demo-web:serve

# 프로덕션 빌드
pnpm exec nx run @berrypjh/demo-web:build
```

## E2E 테스트

```bash
# 헤드리스 실행
pnpm exec nx run @berrypjh/demo-web-e2e:e2e

# UI 모드 (시각적 디버깅)
pnpm exec nx run @berrypjh/demo-web-e2e:e2e-ui
```
